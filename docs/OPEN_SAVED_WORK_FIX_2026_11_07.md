# Saved-work button feedback and conversation navigation

The seller's screenshots show the last-work card and an already restored selected listing directly below it. The previous button only called the same Studio restore function, so pressing it from an already open project did not produce a distinct visible result. It did not open the existing assistant conversation either.

The button now opens a dedicated native modal headed 'Kayıtlı çalışma açıldı', showing the exact selected project, recorded stage, original title, price, scope, full description and thirteen tags. A single modal handles both the history list and project detail rather than stacking native modals. Opening, closing and reopening the details does not regenerate research, product names or listing metadata. Explicit Studio continuation remains available.

Assistant navigation is separate from opening the local project. With no conversation URL saved, the assistant button opens the official ChatGPT/Claude home and explicitly asks the seller to select the existing conversation. It does not claim to know or read the phone's open chat. A seller may bind their private conversation URL to this project for subsequent direct navigation. Only HTTPS chatgpt.com/c/<id> or claude.ai/chat/<id> links matching the selected assistant are accepted; public share, login, query-token, script and foreign-domain links are rejected. The link is kept only in local production records and is not added to outbound prompt text. An invalid optional link cannot discard the underlying saved project.

Regression coverage includes a distinct visible detail screen on actual last-work button presses, repeated close/reopen, unchanged full listing data, no new research, per-product link persistence, invalid-link rejection and exact stored URL navigation after restart. Existing UI-to-Worker upload/draft integration now explicitly continues from the detail modal before uploading. Root/mobile TypeScript and focused tests pass. Full tests, Android/web builds and release checks are recorded with the release.

These checks do not access the seller's real Tosery project store, phone's current ChatGPT conversation or actual generated files. The app cannot infer a private conversation URL from a screenshot or automatically read assistant progress. No assistant message, customer message or Etsy listing is sent or published by this fix.
